## Method and limits

- Source: `git archive` of `origin/main` into a scratch folder, then a script that reads every `SKILL.md` plus the files directly beside it and its `scripts/` folder. No skill, script or job was executed.
- **Risk flags are keyword signals** found in a skill's text or scripts, each shown with the exact matched text. Some matches are examples in documentation, not behaviour. Every flag needs a human check before it is trusted. Flags: deploys, spends money (paid third-party APIs and model calls), contacts people, touches secrets, network, writes files, plus an autonomous signal (cron, daemon, heartbeat, `while true`).
- **GATED** means any of: deploys, spends money, contacts people, or an autonomous signal. I erred toward flagging.
- **Revenue link** is a keyword signal (for example `local seo`, `landing page`, `wholesale`). "none" means no signal found, not "useless".
- **State** is `unknown` for every skill because nothing was run. Where a CI workflow exists for the skill, that is noted; I did not read its results.
- **Overlap** compares skill names and a hash of `SKILL.md`: `identical` means byte-identical, `differs` means same name, different content.
- Not seen: your laptop, the VPS, the live Hermes home, Paperclip, CodeDen, Instinct. PRs #184 to #186 were read as metadata and check results only; I did not read their diffs.
