# When To Use Each Skill

## Prime

- `zero-touch-engineer`: repo scan, implementation loop, test/fix/verify discipline.
- `plan`, `writing-plans`: scoped implementation plans and rollout structure.
- `native-mcp`: MCP connectivity or health checks.

## Engineering

- `github-*`, `codebase-inspection`: repo, branch, PR, CI, and code review tasks.
- `systematic-debugging`, `python-debugpy`, `node-inspect-debugger`: bug and traceback work.
- `docker-management`, `pauli-coolify-ops`, `pauli-vercel-ops`: deployment or runtime repair.

## Studio

- `pauli-open-design`, `pauli-taste-skill`, `pauli-impeccable-design`: UI direction and UX refresh.
- `pauli-video-watch`, `pauli-openmontage-studio`, `pauli-fal-ai`: media workflows and dry-run render planning.
- `browser-harness`: browser verification, frontend walkthroughs, UI debugging.

## Memory And Secrets

- `pauli-supabase-memory`: second-brain retrieval, writeback, and pgvector operations.
- `pauli-infisical-secrets`: env inventory, secret health, secret routing without leaking values.
- `pauli-twilio-voice`: voice status, webhook checks, allowlisted test-call flows.
