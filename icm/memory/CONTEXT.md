# ICM Memory Contract

## Job
Store write-once run evidence, decisions, and promoted recurring patterns.

## Inputs
Only completed run receipts and reviewed decisions.

## Outputs
- `ops/` dated run evidence;
- `decisions/` durable approved decisions;
- `patterns/` repeated verified learnings.

## Rules
Do not store secrets. One result is evidence, not a universal rule. Load memory only when the active instruction requires history.

## Human check
Consequential decisions, policy changes, and client-sensitive pattern promotion require the applicable owner gate.
