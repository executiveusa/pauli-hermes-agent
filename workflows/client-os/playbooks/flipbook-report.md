# Flipbook Report Playbook

## Purpose
Turn the pre-audit into a short client-facing story that earns permission for the first experiment.

## Page sequence
1. Cover — client + Max Digital Media
2. What we reviewed — website, search/local, offers, conversion path, trust signals
3. What is already working
4. Three verified opportunities
5. Recommended first quick win
6. 30-day proof plan
7. How success will be measured
8. Partnership path

## Writing rules
- One idea per page.
- Prefer screenshots, scorecards, before/after examples, and simple charts over paragraphs.
- Separate evidence from hypothesis.
- No fear-based teardown language.
- No invented rankings, traffic, revenue, or conversion claims.

## Approval gate
The client report is not proof until evidence sources are attached and a human verifies client-specific claims.
