# Stage 01 — Story and Source Lock

### Input
- `runs/current/production-spec.yaml`
- selected source media/documents/transcripts

### Process
1. Audit sources, rights, claims, footage and transcript evidence.
2. Build the story/argument spine appropriate to the selected workflow.
3. For factual work, map each material claim to evidence or mark unresolved.
4. Lock spoken script/paper edit far enough to plan shots and actual audio timing.

### Output
- `runs/current/SOURCE_AUDIT.md`
- `runs/current/sources/manifest.json`
- `runs/current/STORY_BRIEF.md` or `runs/current/SCRIPT.md`

### Gate
PASS only when the story has a coherent opening, progression and payoff/CTA, and required factual/source gaps are resolved or explicitly blocked.

### Receipt
Write `runs/current/receipts/01_story_source_lock.json` including external research/source calls.
