# New World Kids fundraising workflow

Use this workflow when the user asks Hermes to fundraise, set up FundRazr, research or draft grants, drive campaign traffic, report fundraising performance, or work with HSI resources for New World Kids.

## Route
- FundRazr campaign setup or improvement → `01_fundrazr/CONTEXT.md`
- Grant discovery/qualification → `02_grant-research/CONTEXT.md`
- Grant writing → `03_grant-draft/CONTEXT.md`
- HSI review/submission → `04_hsi-review/CONTEXT.md`
- Traffic/content → `05_distribution/CONTEXT.md`
- Reporting/learning → `06_reporting/CONTEXT.md`

Always read `references/governance.md` before external actions. Never store sponsor/member credentials in this repo.
