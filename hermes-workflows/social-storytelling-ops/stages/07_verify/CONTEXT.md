# 07 Verify
After export and again after publication, independently verify the artifact. Check MP4 opens, expected duration/aspect/audio/captions/crop, correct account, correct caption/CTA, live URL, and scheduled vs actual publication time. Live-publication verification queries Postiz's `analytics_post`/`posts_list` (see `../../tools.yaml`) for the actual platform-side post state — a local export file or manifest entry claiming "published" is not evidence on its own. Output `verification.json` plus evidence pointers. FAIL means create a bounded correction task; never mark done from provider success alone.
