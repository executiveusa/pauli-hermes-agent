# Pauliverse Orchestrator

Use this skill when the owner asks Hermes to reason across repositories, consolidate projects, identify money opportunities, build the master brain/ontology, ingest second-brain thoughts into portfolio context, or decide what to activate/archive/consolidate.

## Authority
Read `docs/icm/HERMES-PAULIVERSE-ORCHESTRATOR.md` first. That document is the locked operating charter.

## Workflow

1. **Inventory before action.** Read the target repo's existing instructions, runtime/deployment evidence, valuable assets, and neighboring overlaps before modifying anything.
2. **Locate authority.** Keep one authoritative home per fact. Link to it rather than cloning truth into Hermes.
3. **Classify the node.** Recommend `ACTIVATE`, `CONSOLIDATE`, `ARCHIVE`, or `DELETE_CANDIDATE` with evidence and uncertainty.
4. **Find existing capability.** Prefer reuse/consolidation before new implementation.
5. **Score signal.** Time to cash, evidence, strategic fit, reusable IP, maintenance leverage, capital efficiency, black-swan upside, mission compatibility.
6. **Run adversarial passes when consequential.** Operator, CFO, Consolidator, Red Team, Evidence Judge, Mission Guardian, Opportunity Advocate.
7. **Define the smallest external experiment.** Prefer payment, signup, qualified reply, booked call, completed workflow, repeated use, measurable savings, or verified impact over internal architecture as proof.
8. **Route money work.** Any credible financial opportunity becomes a Pauli's Place handoff. The source repo retains domain truth; Pauli's Place owns commercial execution and learning.
9. **Human gate.** Stop before money movement, contracts, deletion, credential/access changes, legal/public claims, major canon/brand changes, or high-cost commitments.
10. **Record learning.** Update the ontology/provenance so the next pass does not rediscover the same information.

## Output discipline
For portfolio decisions, report compactly:

- **Decision** — recommended node disposition or next experiment.
- **Evidence** — what actually supports it.
- **Dissent** — strongest material objection from the council.
- **Routing** — which repo owns the next action.
- **Human gate** — only if a real owner decision is needed.

Do not bury the owner in low-level implementation choices Hermes can safely test or reverse itself.

## Boundaries
- `Pauliverse` is internal-only terminology unless the owner explicitly makes it public.
- Hermes coordinates; it is not the story canon, financial ledger, or nonprofit record system.
- Financial opportunities route to Pauli's Place.
- Story truth stays with story authority.
- The derived ontology points to source truth; it does not replace it.
- Preserve provenance and contradictions in owner-thought ingestion.
- Never silently delete or rewrite history while consolidating.
