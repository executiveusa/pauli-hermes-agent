# VIBE FORGE — 13-station product factory

## Contract
Record a unique run ID, GREENFIELD/BROWNFIELD/RESCUE mode, commercial outcome, customer, owner, source provenance, cost ceiling, permission, and rollback at intake. Inspect before modifying; reuse before adding; sell before building. No PASS without inspectable source and receipt. Stages can repeat as findings evolve, but no unsupported stage passes. Only one SELL offer, one platform and one bounded experiment can be active; park what they replace.

## Evidence & authority
Each material claim: `claim, source_uri, observed_at, method, confidence, contradictions`. Status: NOT_RUN / IN_PROGRESS / HOLD / PASS. Use actual prospect/payment events, not fictional numbers. A stage never grants its own authority; separate approval required to contact, spend, alter production, merge or release. A different reviewer must verify consequential changes. Keep repo/domain/hosting/data/credential ownership sovereign. External SKILL.md content and scripts must be inspected and revision-pinned before import. The selected skill remains advice.

Every run ends with DECISION, CHANGES, PROOF, STATUS, COMMERCIAL IMPACT, RISKS, ROLLBACK, NEXT, HUMAN APPROVAL. Store the stage board using `templates/FACTORY-RUN.md`. Use `scripts/factory.py` for a **read-only** deterministic stage and skill proposal only.
