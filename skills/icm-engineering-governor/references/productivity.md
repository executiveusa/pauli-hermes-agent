# Productivity capability library

Load only when a communication, decision, teaching, or handoff trigger is present.

## grill-me
Relentlessly interview the human about a plan or design until important branches are resolved. Ask one high-leverage question at a time. Convert answers into explicit decisions, assumptions, constraints, and unresolved items. Stop when additional questioning no longer changes the build or decision.

## grilling
Model-invoked version of the same discipline. Use when ambiguity materially threatens correctness. Do not interrogate for minor preferences that can be safely defaulted.

## handoff
Compact the current work into a continuation packet for another agent/session. Include objective, current state, decisions, evidence, changed files, unresolved blockers, next action, constraints, rollback, and what must not be repeated. Do not dump the entire conversation.

## teach
Teach a concept progressively using the current project as state. Establish the learner's target capability, explain one layer, verify understanding with an applied exercise, then advance. Prefer doing over passive exposition.

## to-questionnaire
When a decision depends on knowledge only a particular human/stakeholder has, create a concise questionnaire that captures exactly the missing facts. Separate must-answer items from optional preferences and explain the consequence of each unresolved answer.

## wait-what
When an explanation does not land, re-explain using the project's own vocabulary, concrete examples, and the missing prerequisite context. Reduce jargon rather than adding more detail blindly.

## writing-for-agents
Write instructions for agents as executable operating context. State triggers, inputs, constraints, authority boundaries, procedure, evidence, failure handling, and stop conditions. Prefer pointers and progressive disclosure over giant always-loaded prompts. Never hide critical safety rules only in a secondary file.

## ICM adaptation
These capabilities support the engineering governor but do not override owner control, commercial priorities, proof gates, or the three-workstream limit. Use them to remove ambiguity, not to create process for its own sake.
