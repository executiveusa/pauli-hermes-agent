## Claude Code

Open the folder and ask Claude Code to read `CLAUDE.md`.

## Cursor

Open the folder. Cursor will pick up `.cursor/rules/vercel-imc-agent.mdc`.

## Codex / OpenAI coding agent

Open the folder and point the agent at `.codex/instructions.md` and `AGENTS.md`.

## Windsurf

Open the folder. Windsurf can use `.windsurf/rules/vercel-imc-agent.md`.

Start with:

Read AGENTS.md, then CONTEXT.md. Follow the active stage contract. Do not edit target app source code in Mission 001.
