# Uncodixfy™ Banned Design Language

Never use these words in any client-facing copy, design documentation,
MCP tool descriptions, or skill YAML frontmatter.

**Banned:** innovative, seamless, robust, leverage, synergy, utilize,
revolutionize, transforming, elevating, comprehensive, cutting-edge,
state-of-the-art, intuitive, dynamic, powerful, stunning, beautiful,
world-class, next-generation, holistic, paradigm-shifting, disruptive,
user-friendly, best-in-class, game-changing.

**Replace every banned word with a measurement.**

Examples:
- "seamless integration" → "delivers within 800ms at 99.7% success rate"
- "stunning visuals" → "above-the-fold imagery scores 9.2/10 on IMG axis"
- "intuitive interface" → "primary action reachable in ≤2 clicks with no label"
- "robust platform" → "99.97% uptime, auto-retry on failure, circuit breaker at 3 consecutive errors"
