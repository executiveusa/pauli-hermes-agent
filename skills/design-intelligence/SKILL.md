# Design Intelligence — ICM Skill

## Identity

This skill makes Hermes a student of what's actually winning on the web right now.
It does not generate taste from training data. It reads the scraped feed files,
extracts the mechanisms that make the top sites work, and feeds those mechanisms
as a concrete bar into the Gauntlet Loop and SYNTHIA™ UDEC scoring pipeline.

The difference between this and the `popular-web-designs` skill:
- `popular-web-designs` = static templates of known brands (Stripe, Linear, Vercel)
- `design-intelligence` = live feed of what's *winning today* in the niche you're building for

Use both together: `popular-web-designs` for established vocabulary,
`design-intelligence` for the bar that the current crop of winners is setting.

## Context Budget

Load this skill plus at most 2 feed files at a time. Do not load all niches.
Load only the feed for the relevant niche.

## When to Use

- User asks to build a site for a specific industry or niche
- User asks "what are the best sites for [niche] right now"
- Design Critic phase of the Gauntlet Loop needs a concrete, fetchable bar
- UDEC scoring needs current-market calibration for a niche

## When NOT to Use

- Backend, infrastructure, or API work with no visual deliverable
- The niche is not in `_shared/niches.md` (add it first, then use)

## Workflow

### Step 1 — Identify Niche
Map the user's request to one of the niches in `_shared/niches.md`.
If the niche is missing, add it before proceeding.

### Step 2 — Load Feed

```
skill_view(name="design-intelligence", file_path="_feeds/{niche}-latest.md")
```

If the feed file does not exist, trigger `awwwards-scraper` to generate it
before continuing.

### Step 3 — Extract Mechanisms
From the feed file, extract 5–7 checkable mechanisms in this format:
- Measurable, not adjective-based
- Something a critic can verify by looking at the rendered output
- Examples: "hero type is 5× body size", "one accent color, used ≤2× per screen",
  "no animation under 400ms", "whitespace above fold ≥40% of viewport height"

Write these to `bar.md` in the working directory.

### Step 4 — Run Design Critic (optional, on request)
Load `sub-skills/design-critic/SKILL.md` and execute the Gauntlet Loop
against the mechanisms in `bar.md`.

### Step 5 — UDEC Score (on delivery)
Every visual deliverable that passes through this skill gets scored against
`_shared/udec-axes.md`. Floor: 8.5. Below 8.5 → iterate. Do not ship.

## Output Contract

- `_feeds/{niche}-latest.md` — scraped feed (generated by cron, consumed here)
- `bar.md` — extracted mechanisms for Gauntlet Loop critic
- UDEC scorecard as a markdown table appended to the deliverable
- Nothing ships below 8.5/10 overall, below 7.0 on MOT or ACC
