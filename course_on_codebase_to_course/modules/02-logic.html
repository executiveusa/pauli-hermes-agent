Mapping the Actors

Every codebase has a "cast." Some files handle the UI, some handle the persistence, and some handle the logic. By identifying these actors, the course can explain them as if they are talking to each other.

ℹ️
The "Who" over the "How"

For a vibe coder, knowing which file is responsible for a feature is more important than knowing the exact code inside it. This allows them to tell an AI agent: "Go to the Storage Actor and add a new field."

Tracing the Journey

The AI looks for the Primary User Journey. If you're building a podcast app, it traces what happens from the moment you paste a URL to the moment the audio plays. This becomes the spine of the course.
